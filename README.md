# neFibonacci
NeFibonacci is an interactive mathematical visualizer that calculates generalized and higher-order Fibonacci sequences, rendering their recursive growth and harmonic frequency patterns as radiant, glowing 3D spirals in real time.
NeFibonacci
Interactive Streamlit web application that calculates generalized ￼-step Fibonacci sequences and visualizes their growth, modular cycles, and harmonic structures as radiant 3D curves.
Overview
￼ Generalized Sequences: Compute standard Fibonacci (￼), Tribonacci (￼), Tetranacci (￼), and higher-order series.
￼ Harmonic & Modular Analysis: Computes binary parity (n \pmod 2) and Pisano-style modular cycles (n \pmod m) to color-code geometric paths.
￼ Radiant 3D Visualizer: Generates dynamic 3D parametric spirals using Plotly.
￼ Export: Built-in CSV export for external research and data inspection.
